## Brand & Style

The design system embodies a brutalist-refined, dark industrial aesthetic engineered for high-performance collegiate robotics. Rooted in structural rigor, precision hardware engineering, and anti-gravity kinetic confidence, the interface balances unapologetic raw power with surgical elegance.

### Aesthetic Ethos
- **Brutalist-Refined Precision:** Structural grid frameworks, raw technical numbering, monospaced indexing, and exposed architecture paired with hyper-refined typography and calibrated spacing.
- **Architectural Void:** Massive negative space built upon deep void black, letting illuminated hardware, technical schematics, and high-impact typography float with weightless authority.
- **Industrial Telemetry:** Inspired by aerospace telemetry readouts, robotic combat schematics, and Swiss minimalist editorial design. Every accent, micro-badge, and division line exists with deliberate functional purpose.

## Colors

The palette operates in extreme contrast, establishing clear depth layers across dark spatial planes without muddying visual clarity.

### Color Roles & Mechanics
- **Base Void (`#0A0A0A`):** The primary ground surface. Deep, non-reflective canvas that maximizes screen contrast and focuses attention strictly on active mechanical content.
- **Surface Elevation (`#121212` & `#1A1A1A`):** Muted carbon-tinted planes utilized for bento cards, telemetry panels, and containerized modules.
- **Primary Text (`#F5F5F7`):** Pure surgical off-white designed for immediate high-contrast legibility against the void background.
- **Secondary Text (`#8E8E93`):** Neutralized cold gray used for secondary labels, body specs, and operational metadata.
- **Industrial Amber (`#FFB800`):** Reserved strictly for functional accents: status flags, active states, numerical tags, verification badges, and focal indicators. It should never be used as large flood backgrounds.
- **Hairline Boundaries (`rgba(255, 255, 255, 0.08)`): Zero-fill separation lines providing surgical definition without heavy visual mass.

## Typography

Typography establishes an assertive architectural cadence across the interface. 

### Typographic Hierarchy & Logic
- **Display & Section Titles (`Space Grotesk`):** High-impact, technical geometric headers set in tight tracking (`-0.04em` to `-0.02em`). All hero banners and primary declarations leverage uppercase or disciplined title casing.
- **Section Structural Markers:** Section headings use an explicit industrial indexing syntax (e.g., `01 // THE FLEET`, `02 // THE ARENA`, `03 // THE FOUNDATION`). The numeric index is formatted with `JetBrains Mono` at `label-structural` scale in amber, followed by the headline in `Space Grotesk`.
- **Editorial Body Copy (`Inter`):** Clean, neutral, and utilitarian. Generous line heights (`1.6`) ensure readability against the dark void without optical fatigue.
- **Telemetry & Labels (`JetBrains Mono`):** Monospaced technical notation for hardware specs (e.g., `RPM: 12000`, `ARMOR: HARDOX 450`, `STATUS: DEPLOYED`).

## Layout & Spacing

The layout philosophy is predicated on a fluid bento-grid system flanked by generous negative space. Spacing does not serve as passive padding; it acts as structural silence that reinforces high-end engineering precision.

### Layout Principles
- **Grid Architecture:** 12-column asymmetric fluid grid on desktop, folding into a 6-column grid on tablet, and a single or dual-column stacked layout on mobile.
- **Outer Canvas Margins:** Desktop viewports enforce a strict `margin-desktop: 4rem` (64px) minimum boundary, isolating the content matrix from browser edges.
- **Bento Modules:** Components span uneven modular proportions (`2x2`, `2x1`, `1x1`) to generate an intentional structural cadence. 
- **Section Isolation:** Vertical separation between thematic zones leverages extended pauses (`space-2xl` to `space-3xl`) to establish architectural chapter breaks.

## Elevation & Depth

This design system rejects conventional drop shadows, blurred ambient halos, and skeuomorphic gradients. Depth is achieved purely through layered tonal planes and illuminated micro-hairlines.

### Depth Mechanics
- **Ground Floor:** `#0A0A0A` base background.
- **Tonal Plane 1 (Structural Containers):** `#121212` with a uniform `1px solid rgba(255, 255, 255, 0.08)` border.
- **Tonal Plane 2 (Active/Elevated Modules):** `#1A1A1A` with a crisp `1px solid rgba(255, 255, 255, 0.14)` border.
- **Dynamic Interaction State:** On hover, elevated cards transition with an ultra-thin border highlight shift from `rgba(255, 255, 255, 0.08)` to `rgba(255, 184, 0, 0.6)`, accompanied by a calibrated scale transformation (`scale(1.015)`) with an ease-out curve (`cubic-bezier(0.16, 1, 0.3, 1)`).
- **Backdrop Diffusion:** Floating technical toolbars and fixed corner navigation modules use `rgba(18, 18, 18, 0.8)` with a tight 16px backdrop blur, anchored by a hairline border.

## Shapes

The geometric vernacular is unapologetically sharp (`roundedness: 0`), reflecting machined metal, carbon fiber cutouts, and industrial hardware chassis.

### Form Characteristics
- **Right Angles:** All cards, buttons, badges, banners, inputs, and image enclosures utilize `0px` border-radius.
- **Corner Notches (Special Display Elements):** High-priority modules or tactical telemetry cards may feature single-corner 45-degree chamfers (cut corners of 8px to 12px) implemented via CSS clip-path, reinforcing military-grade industrial avionics aesthetics.
- **Precision Dividers:** Separators must be strictly 1px hairlines without drop shadow or vertical displacement.

## Components

### Buttons
- **Primary Action:** Solid off-white `#F5F5F7` background with jet-black `#0A0A0A` typography in `Space Grotesk` medium. Completely square corners (`0px`). Padding: `12px 24px`. Hover state: Inverts to `#FFB800` background with instant micro-transition.
- **Secondary Action (Ghost Industrial):** Transparent background, `1px solid rgba(255, 255, 255, 0.14)`, `#F5F5F7` typography. Hover state: `border-color: #FFB800`, text tinted with `#FFB800`.
- **Command / Link Button:** Pure typography accompanied by an aligned directional arrow (`→`), monospaced numbering, and an animated 1px underline that expands from left to right.

### Badges & Status Chips
- **Status Indicator:** Sharp container with `rgba(255, 184, 0, 0.1)` background and `1px solid rgba(255, 184, 0, 0.3)`. Text set in `JetBrains Mono` 11px uppercase in `#FFB800`.
- **Live / System Ping:** Features a 6px glowing `#FFB800` dot with a subtle pulse animation preceding the badge copy (e.g., `● FABRICATION PHASE`).

### Bento Cards
- **Architecture:** Solid `#121212` background, `1px solid rgba(255, 255, 255, 0.08)`. Internal padding: `space-xl` (2.5rem).
- **Content Hierarchy:** Top-right monospaced index (e.g., `FLEET // 01`), center focal point (high-contrast schematic render or large stat), bottom metadata container displaying technical telemetry specifications.
- **Interactive State:** Border brightness increases on hover with a micro-scale shift (`scale(1.015)`).

### Data Lists & Competition Tables
- **Layout:** Architectural horizontal row list. Each row separated by `1px solid rgba(255, 255, 255, 0.08)`.
- **Structure:** 
  1. Position / Rank (`01` in `#FFB800` monospaced).
  2. Competition name in bold `Space Grotesk`.
  3. Venue / Host Institution in muted `Inter` (`#8E8E93`).
  4. Status / Result tag flush right.
- **Hover State:** Row background smoothly shifts to `rgba(255, 255, 255, 0.03)` with horizontal text translation of 4px to the right.

### Input Fields
- **Container:** Dark surface `#0A0A0A`, `1px solid rgba(255, 255, 255, 0.14)`, sharp corners.
- **Typography:** `Inter` 14px text in `#F5F5F7` with placeholder text in `#48484A`.
- **Focus State:** Hairline border turns `#FFB800` with zero outline blur, accompanied by an amber mono label pinned directly to the upper-left boundary.

### Floating Micro-Dock / Navigation
- **Dock Placement:** Pinned floating navigation anchored at the bottom viewport edge or split across screen corners.
- **Styling:** Frosted dark panel (`rgba(18, 18, 18, 0.85)` with backdrop blur), sharp edges, hairline border (`rgba(255, 255, 255, 0.12)`). Monospaced uppercase navigation items separated by vertical pipes (`|`).
